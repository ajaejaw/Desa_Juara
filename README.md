# Festival Desa Juara (Project GIM)

Game simulasi perayaan kemerdekaan (17 Agustusan) dengan nuansa desa pixel art, dibuat menggunakan engine GDevelop. Pemain dapat menjelajahi desa dan mengikuti berbagai lomba tradisional.

## 🎮 Fitur Game

Game ini terdiri dari *Hub* utama (Desa) dan beberapa *Minigame* tradisional:

* **Hub Desa**: Area utama untuk eksplorasi dan memilih permainan.
* **Balap Karung** (`Game_Karung`): Lomba melompat menggunakan karung hingga garis finis.
* **Makan Kerupuk** (`Game_Kerupuk`): Minigame ketepatan memakan kerupuk.
* **Panjat Pinang** (`Game_Pinang`): Lomba memanjat tiang licin untuk mengambil hadiah.
* **Sistem Ending**: Terdapat *Good Ending* dan *Bad Ending* tergantung pada jumlah kemenangan pemain (`Jumlah_Kemenangan`).

## 🛠️ Teknologi yang Digunakan

* **Engine**: [GDevelop 5](https://gdevelop.io/) (versi 5.6)
* **Resolusi Game**: 640x360 px (Pixel Art style)
* **Format**: HTML5 / Desktop Game

## 🕹️ Cara Bermain (Kontrol)

### Navigasi Menu & Hub
* **Gerakan**: Tombol Panah (Kiri/Kanan)
* **Interaksi / Masuk Lomba**: Tekan `Enter` (Return) saat berada di dekat pos lomba (Pos Karung, Pos Kerupuk, dll).

### Minigames
* **Lompat (Balap Karung),Lompat (Kerupuk) dan Lompat (Panjat Pinang)**: Tekan `Spasi`.
* **Aksi Lainnya**: Menggunakan tombol `Spasi` atau `Enter` sesuai instruksi di layar.

## 🚀 Cara Menjalankan Project

1.  Pastikan Anda telah menginstal **GDevelop 5**.
2.  Clone repository ini atau download file `.zip`.
3.  Buka GDevelop, pilih **Open a project**.
4.  Pilih file `Project GIM final - .json`.
5.  Klik tombol **Preview** untuk memainkan game.

## 📂 Struktur Project

* `Project GIM final - .json`: File utama proyek GDevelop.
* `assets/`: Folder berisi sprite karakter (Ninja Frog, dll), tileset (Sunny Land), dan audio.
